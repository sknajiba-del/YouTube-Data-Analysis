📊 Apple Watch vs Samsung Galaxy Watch Ultra: Social Media Analytics
Overview

This project analyses YouTube engagement data to compare the Apple Watch Series 10 and the Samsung Galaxy Watch Ultra using social media analytics. The objective is to identify consumer engagement patterns and generate innovation opportunities by applying the Ideation stage of the Social Media for Open Innovation Implementation Framework (Mount & Martinez, 2014).

Objectives
Collect YouTube metadata for two competing smartwatch products.
Compare audience engagement using quantitative social media metrics.
Identify differences in visibility, engagement, and influencer impact.
Generate data-driven innovation recommendations for Apple Watch Series 10.

Dataset

The datasets were collected from YouTube using the YouTube Data API through Google Colab.

Each dataset contains metadata including:

View count
Like count
Comment count
Channel name
Video title
Publication date
Video ID

A sample of 20 review videos was collected for each product.

Analysis Performed

The project includes:

Time Series Analysis of Likes & Comments,
Total View Count Comparison,
Like-to-View Engagement Ratio,
Likes vs Comments Scatterplots,
Total Likes & Comments by Channel,
Influencer Performance Comparison

Key Findings
Apple Watch Series 10 generated significantly greater market visibility and launch momentum.
Samsung Galaxy Watch Ultra achieved higher audience engagement relative to its viewership.
Apple's online visibility relied heavily on a small number of high-profile technology reviewers, while Samsung's engagement was distributed across a broader range of creators.

Innovation Recommendations

Based on the comparative analysis:

Incremental Innovation
Improve battery performance through hardware optimisation and enhanced power management.
Radical Innovation
Increase water resistance to better compete within the premium outdoor smartwatch market.

These recommendations align with the Ideation stage of the Mount & Martinez (2014) framework.
